用 GitHub Pages 免费搭建个人网站

2026-10-01 · 标签：建站 教程

本站就跑在 GitHub Pages 上，零成本。把流程整理一下，有手就能复刻。

1. 建仓库，开 Pages

新建一个叫 用户名.github.io 的公开仓库，把 HTML 文件传上去，然后在仓库 Settings → Pages 里选择从 main 分支部署。几分钟后，用户名.github.io 就能访问了。

2. 评论区：用 giscus

静态站没有后端，评论可以用 giscus（基于 GitHub Discussions）。去 giscus 官网按向导生成一段代码，粘进页面就行，本站论坛就是这么做的。

3. 联系表单：用 FormSubmit

表单提交到 formsubmit.co/ajax/你的邮箱，首次提交后去邮箱点一下激活邮件，之后留言就会发到你邮箱。记得先自己测试一条。

4. 访问统计：用 Vercount

加一行 JS 引用，再放两个显示数字的 span，页脚就有"总访问量"了。别用不蒜子，它的计数接口已经挂了。

5. 别忘了 SEO 基础

sitemap.xml、robots.txt、每个页面的 title 和 description、分享时的 og:image，这几样加上，搜索引擎才愿意收录你。

遇到问题可以来论坛问我。
