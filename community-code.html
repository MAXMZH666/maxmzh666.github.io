Scratch 在线编程

在浏览器里直接编程（TurboWarp 编辑器），做完导出 .sb3 去发布页上传，作品就能上线了。

三步发布：① 点下面按钮打开编辑器编程 → ② 编辑器左上角 文件 → 保存到电脑，得到 .sb3 文件 → ③ 去发布作品上传。
💻 打开在线编辑器 📤 去发布作品
小提示：TurboWarp 不允许把编辑器嵌进别的网页，所以这里用新标签页打开，功能完全一样。 已有 Scratch 作品想继续改？去它的试玩页点"在在线编程里继续编辑"，编辑器会自动载入那个作品。
