📦 Scratch 打包

把 Scratch 作品打包成 HTML 网页、ZIP 或 Windows/macOS/Linux 可执行文件，离线也能玩，发给朋友更方便。

  1. 打开 TurboWarp Packager →
  2. 粘贴 Scratch 作品链接，或上传本地 .sb3 文件
  3. 选 HTML / ZIP / 可执行文件，一键导出

打开打包工具 →

打包工具由 TurboWarp 提供，本站仅做导航。
